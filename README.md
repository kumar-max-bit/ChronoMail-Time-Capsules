# Time-Capsules
Fullstack web application for making scheduled emails using React.js and an Express backend using Nodemailer. 

## Features
- **Schedule Emails:** Create emails and set them to be delivered at a specific future date and time.
- **Attachments:** Support for attaching files to your scheduled emails.
- **User-friendly Interface:** A clean and intuitive UI built with React.

## Technologies Used
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Email Service:** Nodemailer
- **Database:** MongoDB / Mongoose
- **File Uploads:** Multer
